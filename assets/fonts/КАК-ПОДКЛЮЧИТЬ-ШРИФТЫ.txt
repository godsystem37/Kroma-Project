ПОЧЕМУ LUNNA НЕ РАБОТАЕТ СЕЙЧАС
================================
В папке assets/fonts/ нет файлов шрифта — только этот текст.
Браузер не может скачать шрифт из Figma сам.
CSS уже настроен, нужны только файлы .otf / .woff2 на диске.


ЧТО НУЖНО ИЗ FIGMA (и не только)
=================================

1) ФАЙЛЫ ШРИФТОВ (главное)
   Figma НЕ экспортирует шрифты вместе с макетом.
   Нужно получить файлы у дизайнера или там, где купили шрифт:

   LUNNA Regular 400  →  положи сюда как:
     LUNNA.otf   или   LUNNA.woff2

   AA Stetica Medium 500  →  для подписей на карточках каталога:
     AAStetica-Medium.otf   или   .woff2

   Как узнать точное имя в Figma:
     Выдели текст → правая панель → имя шрифта (LUNNA / AA Stetica).

   Если шрифт установлен на Mac:
     Иногда помогает без файла (local), но для сайта лучше всегда положить .woff2.


2) ИЗ FIGMA МОЖНО ВЗЯТЬ (уже есть / по желанию)
   ✓ Картинки — PNG/JPG экспорт слоёв (у тебя уже в assets/)
   ✓ Логотип — SVG или PNG с прозрачным фоном
   ✓ Иконки преимуществ — SVG/PNG
   ✓ Цвета — скопировать HEX из Fill (уже примерно в CSS)
   ✓ Отступы — из Inspect (padding между секциями)

   Не обязательно из Figma:
   ✗ leading-trim — в вебе почти не поддерживается, игнорируем
   ✗ шрифт «из ссылки» — только если это Google Fonts (LUNNA — нет)


3) ПОСЛЕ КОПИРОВАНИЯ ФАЙЛОВ
   Обнови страницу: Cmd + Shift + R
   В DevTools → Elements → Computed → font-family должно быть LUNNA


ИМЕНА ФАЙЛОВ (любой вариант сработает)
   LUNNA.woff2 / LUNNA.otf / Lunna.woff2
   AAStetica-Medium.woff2 / AAStetica-Medium.otf
